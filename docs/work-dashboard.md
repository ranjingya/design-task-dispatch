# 工作看板

看板为飞书「月度工作量与及时性」，使用多维表格公式与仪表盘组件实时计算。

## 月份与人员

- 顶部「月份筛选」同时筛选任务指标、交付及时性、任务明细、成员月负载分和四类工作占比。月份格式为 `YYYY-MM`，勾选一个月份查看当月，勾选多个连续或跨年月份查看累计数量和占比。
- 需求任务表按截止月份筛选；成员月度负荷表按「月份」筛选；京东创意图、两张优化需求表及两张新品数据包表按完成月份筛选。
- 「人员筛选」同时作用于上述图表。需求任务使用最终负责人；其他来源使用对应的负责人。多人任务在每位成员的个人统计中各计一次，在全员任务总数中按源记录计一次。

## 交付及时性

按日期比较实际完成时间和截止时间：

| 分类 | 条件 |
| --- | --- |
| 提前完成 | 完成日期早于截止日期 |
| 当天完成 | 完成日期与截止日期相同 |
| 逾期完成 | 完成日期晚于截止日期 |
| 逾期未完成 | 截止日期早于今天，实际完成时间为空 |

已取消、未设截止日期及尚未到期的未完成任务不参与交付分布。按期完成率的分母为截至昨日到期、未取消且已有最终负责人的任务；分子为其中提前或当天完成的任务。

## 四类工作占比

按完成任务数量计算占比，一条符合条件的源记录计一个任务。

| 类别 | 来源表 | 完成日期 | 负责人 |
| --- | --- | --- | --- |
| 部门需求 | 需求任务表 | 实际完成时间 | 最终负责人 |
| 创意图 | 京东创意图 | 完成日期 | 负责人映射到成员负荷表人员 |
| 优化需求 | 杭州优化需求 | 完成时间 | 负责人 |
| 优化需求 | 部门优化需求 | 完成时间 | 负责人 (人员 ) |
| 数据包 | 2026-新品数据包、2027-新品数据包 | 完成日期 | 负责人映射到成员负荷表人员 |

杭州优化需求中的「上新」与「优化」都计入优化需求。需求任务表中已取消的记录、已关联京东创意图的记录不计入部门需求。创意图按其来源记录统计，关联需求中的同一项工作不重复计入部门需求。

完成日期非空是四类工作占比的统计条件，月份归属使用上方约定的各来源月份字段。勾选完成但未填写日期的记录需补充真实完成日期后才能参与统计。没有记录的类别数量为 0，饼图仅展示有数据的类别。

## 自动计算字段

六张来源表的「统计工作类别」使用固定分类公式，「工作完成月份」按各自的完成日期生成月份。京东创意图及两张新品数据包表的「统计负责人」根据成员负荷表人员姓名中的昵称映射负责人，人员名单随成员负荷表变化。

这些字段在已有日常视图中隐藏。业务人员维护原有负责人和完成日期，飞书自动更新图表；服务器的评级、推荐与当前负载计算按各自配置运行。
