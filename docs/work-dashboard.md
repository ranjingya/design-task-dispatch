# 工作看板

看板为飞书「月度工作量与及时性」，使用多维表格公式与仪表盘组件实时计算。

## 月份与人员

- 顶部「月份筛选」按提交月份同时筛选任务指标、交付及时性、任务明细、成员月负载分和四类工作占比。月份格式为 `YYYY-MM`，勾选一个月份查看当月，勾选多个连续或跨年月份查看累计数量和占比。
- 七张工作来源表使用隐藏公式「提交月份」；成员月度负荷表使用「月份」文本列。月度负荷分数按需求任务的提交月份汇总，包含已完成与未完成任务。
- 「人员筛选」同时作用于上述图表。需求任务使用最终负责人；其他来源使用对应的负责人。多人任务在每位成员的个人统计中各计一次，在全员任务总数中按源记录计一次。
- 提交时间优先使用已有业务日期；缺失时使用当前记录创建时间。历史数据导入或复制后，缺失原始提交日期的记录归属导入或复制月份。

## 交付及时性

按日期比较实际完成时间和截止时间：

| 分类 | 条件 |
| --- | --- |
| 提前完成 | 完成日期早于截止日期 |
| 当天完成 | 完成日期与截止日期相同 |
| 逾期完成 | 完成日期晚于截止日期 |
| 逾期未完成 | 截止日期早于今天，实际完成时间为空 |

已取消、未设截止日期及尚未到期的未完成任务不参与交付分布。按期完成率的分母为所选提交月份内、截至昨日到期、未取消且已有最终负责人的任务；分子为其中提前或当天完成的任务。

## 四类工作占比

按提交任务数量计算占比，包含未完成任务。一条有效源记录计一个任务，空白占位记录不计入。

| 类别 | 来源表 | 提交时间依据 | 负责人 |
| --- | --- | --- | --- |
| 部门需求 | 需求任务表 | 提交时间（记录创建时间） | 最终负责人 |
| 创意图 | 京东创意图 | 提交时间，缺失时使用记录创建时间 | 负责人映射到成员负荷表人员 |
| 创意图 | 拼多多创意图 | 提交时间（记录创建时间） | 负责人 (人员 ) 映射到成员负荷表人员 |
| 优化需求 | 杭州优化需求 | 发布时间，缺失时使用记录创建时间 | 负责人 |
| 优化需求 | 部门优化需求 | 提交时间（记录创建时间） | 负责人 (人员 ) |
| 数据包 | 2026-新品数据包、2027-新品数据包 | 提交时间（记录创建时间） | 负责人映射到成员负荷表人员 |

杭州优化需求中的「上新」与「优化」都计入优化需求。需求任务表中已取消的记录、已关联京东创意图的记录不计入部门需求。创意图按其来源记录统计，关联需求中的同一项工作不重复计入部门需求。

有效记录以各来源的任务名称、品名、货号品名或商品名称非空为准。没有记录的类别数量为 0，饼图仅展示有数据的类别。任务是否完成、是否有完成日期，不影响四类提交量。

## 自动计算字段

七张来源表的「统计工作类别」使用固定分类公式，「提交月份」按各自的提交时间依据生成月份。京东创意图及两张新品数据包表的「统计负责人」根据成员负荷表人员姓名中的昵称映射负责人；拼多多创意图根据负责人身份筛选成员负荷表中的美工。人员名单随成员负荷表变化。

统计辅助字段与日期缺失回退使用的「记录创建时间」在日常视图中隐藏。业务人员维护原有提交日期、负责人、截止日期和完成日期，飞书自动更新图表；服务器的评级、推荐与当前负载计算按各自配置运行。
