# 人员推荐规则说明

「推荐规则」供人查看，程序使用项目本地配置执行。其他推荐方式的推荐规则留空。

## 店铺装修｜市场部

适用于两条市场部店铺装修规则。

- 店铺 → 主负责人（备选）
- 京东POP → 饭团（塔可）
- 京东自营 → 软糖（蛋糕、青提）
- 拼多多官方旗舰店 → 塔可（饭团）
- 拼多多旗舰店／雨具店 → 青提（蛋糕）
- 拼多多儿童服饰旗舰店 → 蛋糕（塔可）
- 拼多多母婴玩具店／箱包店 → 软糖（青提）
- 欢趣专卖店 → 青提（蛋糕）
- 运动户外旗舰店 → 软糖（饭团）

## 店铺装修｜渠道部

适用于两条渠道部店铺装修规则。

- 阿里巴巴湖州趣行 → 饭团（塔可）
- 阿里巴巴杭州萌途 → 饭团（蛋糕）
