# 人员推荐规则说明

规则表的「推荐方式」表示默认推荐策略，「推荐规则」供业务人员阅读和核对。程序通过项目本地结构化配置及代码执行推荐；展示文字不在运行时解析执行。规则调整后，应核对本地配置、测试结果和部署资源，确认生效版本。

本文对应规则表的 26 条记录，以记录 ID 区分同名工作类型。

## 通用约束

- 花菜不参与美工分配；查到其为对应人员时，交由人工分配。
- 系统推荐由组长确认，最终负责人及确认结果以需求任务表为准。
- 已指定最终负责人、已确认、已完成或已取消的任务，保留人工处理结果。

## 待明确事项

- 数据包创意图中，PDD「其他人员」具体排除谁，需要明确。
- 数据包创意图的人员负载分数尚未填写。
